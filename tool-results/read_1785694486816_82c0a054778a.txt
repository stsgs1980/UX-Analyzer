   234→### 2.3 Animation System
   235→
   236→All sections are wrapped in `AnimatedSection` — a `framer-motion` `motion.div`:
   237→
   238→```tsx
   239→initial={{ opacity: 0, y: 20, scale: 0.98 }}
   240→whileInView={{ opacity: 1, y: 0, scale: 1 }}
   241→viewport={{ once: true }}
   242→transition={{ duration: 0.8, ease: [0.33, 1, 0.68, 1], delay }}
   243→```
   244→
   245→**Animation profile**: Subtle fade-in + upward slide + slight scale (0.98→1). Cubic-bezier easing `[0.33, 1, 0.68, 1]` = ease-out-quint. Duration: 0.8s. Each section has a staggered delay (0, 0.1, 0.2s).

   334→## 4. Patterns — Reusable Design Patterns
   335→
   336→### 4.1 Glassmorphism Card Pattern
   337→
   338→Used across bento cards, CTA backgrounds, and testimonials:
   339→
   340→```tsx
   341→// Background layers
   342→<div className="absolute inset-0 rounded-2xl"
   343→  style={{
   344→    background: "rgba(231, 236, 235, 0.08)",
   345→    backdropFilter: "blur(4px)",
   346→  }} />
   347→<div className="absolute inset-0 bg-gradient-to-br from-white/5 to-transparent rounded-2xl" />
   348→// Content
   349→<div className="relative z-10 ...">{children}</div>
   350→```
   351→
   352→**Key properties**: Semi-transparent bg, backdrop-filter blur, gradient overlay, z-index stacking.
   353→
   354→### 4.2 Animated Section Wrapper Pattern
   355→
   356→Every major section is wrapped:
   357→
   358→```tsx
   359→<AnimatedSection className="relative z-10 max-w-[1320px] mx-auto mt-8 md:mt-16" delay={0.2}>
   360→  <SectionComponent />
   361→</AnimatedSection>
   362→```
   363→
   364→This ensures consistent scroll-triggered animations with staggered timing.
   365→
   366→### 4.3 SVG Gradient Background Pattern
   367→
   368→Hero and CTA sections use complex SVG compositions:
   369→
   370→```tsx
   371→<svg viewBox="0 0 1220 810" preserveAspectRatio="xMidYMid slice">
   372→  <mask>...</mask>           // Alpha mask for gradient falloff
   373→  <g filter="url(#blur)">     // Gaussian blur group
   374→    <path fill="url(#gradient)" />  // Gradient shape
   375→  </g>
   376→  <g style={{ mixBlendMode: "lighten" }}>...</g>  // Blend mode layer
   377→</svg>
   378→```
   379→
   380→**Technique**: Layered gradient paths with different blur radii and blend modes create depth without actual images.
   381→
   382→### 4.4 BentoCard Composite Pattern
   383→
   384→```tsx
   385→const BentoCard = ({ title, description, Component }) => (
   386→  <div className="overflow-hidden rounded-2xl border border-white/20 flex flex-col">
   387→    {/* Glass background */}
   388→    <div className="absolute inset-0" style={{ background: "rgba(..., 0.08)", backdropFilter: "blur(4px)" }} />
   389→    {/* Text area */}
   390→    <div className="relative z-10 p-6">
   391→      <p className="text-lg">{title}<br /><span className="text-muted-foreground">{description}</span></p>
   392→    </div>
   393→    {/* Illustration area - fixed height */}
   394→    <div className="h-72 relative z-10">
   395→      <Component />
   396→    </div>
   397→  </div>
   398→)
   399→```
   400→
